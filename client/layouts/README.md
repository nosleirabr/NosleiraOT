# `client/layouts`

Overlays de UI. O produto usa **`retro`** (`DEFAULT_LAYOUT` em `init.lua`).

Regra OTCv8: arquivos em `/layouts/<nome>/...` sombreiam o mesmo path relativo sob `/data/...`.

`retro/` traz estilos, ícones de top buttons e arte “clássica”, mas ainda inclui imagens de sistemas modernos (prey, shop, bot) — remoção cosmética é fase posterior.
