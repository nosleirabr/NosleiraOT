24px —

Itens

Clique na paleta e no mapa para colocar. Clique seleciona. Ctrl+arrastar navega. Del apaga. Ctrl+C/V/Z copia, cola e desfaz.

Spawns

Clique num nome e depois no mapa para colocar. Arraste o monster para mudar a posição.

Propriedades

Clique = selecionar · Ctrl+arrastar = pan · scroll = zoom · WASD = câmera. Ctrl+F = ir para posição. Del = apagar. Ctrl+Z = desfazer.
